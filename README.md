# 조각로그 · Mosaic Log

대사와 나레이션을 꾸미고, 완성한 로그를 HTML로 내보내는 웹 도구입니다.

[바로 사용하기](https://mosaic-log.github.io/) · [업데이트 내역](https://github.com/mosaic-log/mosaic-log.github.io/releases) · [오류 제보·제안](https://github.com/mosaic-log/mosaic-log.github.io/issues)

## 사용 방법

1. [조각로그](https://mosaic-log.github.io/)에 접속합니다.
2. 본문 탭에서 글을 입력합니다. 본문 문법은 작업 화면의 안내를 참고합니다.
3. 표지·디자인·테마 탭에서 필요한 항목과 모양을 설정합니다.
4. 미리보기에서 결과를 확인하고 수정합니다. 문장을 직접 편집할 때는 `Enter`로 저장하고 `Esc`로 취소합니다.
5. **HTML 복사하기**로 완성한 HTML을 복사해 게시글 작성기의 HTML 모드에 붙여넣거나, **HTML 내보내기**로 파일을 저장합니다.

표지나 프로필에 사진을 넣으려면 해당 항목에 이미지 URL을 입력합니다.

## 저장과 백업

현재 작업은 사용 중인 브라우저에 자동 저장됩니다. 작업을 따로 보관하려면 보관함에 저장합니다. 다른 기기나 브라우저로 자동 동기화되지는 않습니다.

보관함의 **내보내기**로 JSON 백업을 만들고 **파일 가져오기**로 복원할 수 있습니다. HTML 내보내기·불러오기는 개별 작업을 옮길 때 사용할 수 있습니다.

## 내려받아 실행하기

1. [Releases](https://github.com/mosaic-log/mosaic-log.github.io/releases)에서 압축 파일을 내려받습니다.
2. 압축을 모두 해제하고 같은 폴더의 `index.html`을 브라우저에서 엽니다.

설치·빌드 과정은 없습니다. HTML·CSS·JS 파일을 같은 폴더 구조로 유지합니다. 웹폰트와 이미지 URL은 인터넷 연결이 필요하며, 웹사이트와 로컬 파일의 저장 공간은 다릅니다.

## 직접 수정하기

수정한 파일을 그대로 실행할 수 있습니다. 파일 구조와 수정 방법은 [개조 안내](MODDING.md), 유지보수 원칙은 [AGENTS.md](AGENTS.md)를 참고합니다.

## 오류 제보·제안

[Issues](https://github.com/mosaic-log/mosaic-log.github.io/issues)에 사용 버전, 브라우저, 재현 순서를 남겨 주세요. 문제가 생기는 짧은 예시 본문이나 화면이 있으면 확인에 도움이 됩니다.
