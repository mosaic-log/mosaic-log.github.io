# 조각로그 · Mosaic Log

대사와 나레이션을 꾸미고, 완성한 로그를 HTML로 내보내는 웹 도구입니다.

[바로 사용하기](https://mosaic-log.github.io/) · [업데이트 내역](https://github.com/mosaic-log/mosaic-log.github.io/releases) · [오류 제보·제안](https://github.com/mosaic-log/mosaic-log.github.io/issues)

## 사용 방법

1. [조각로그](https://mosaic-log.github.io/)에 접속합니다.
2. 본문 탭에서 글을 입력합니다. 본문 문법은 작업 화면의 안내를 참고합니다.
3. 표지·디자인·테마 탭에서 필요한 항목과 모양을 설정합니다.
4. 미리보기에서 결과를 확인하고 수정합니다. 문장을 직접 편집할 때는 `Enter`로 저장하고 `Esc`로 취소합니다.
5. **HTML 복사하기**로 완성한 HTML을 복사해 게시글 작성기의 HTML 모드에 붙여넣거나, **HTML 저장하기**로 파일을 저장합니다.

표지나 프로필에 사진을 넣으려면 해당 항목에 이미지 URL을 입력합니다.

코멘트도 `[접기 제목]`과 `[/접기]`를 각각 독립된 줄에 입력해 일부를 접을 수 있습니다. 코멘트의 접기는 별도 장식 없이 브라우저 기본 `details`·`summary`로 표시합니다. 제목을 생략하면 ‘접기’로 표시하고, 닫는 문법을 생략하면 코멘트 끝까지 묶습니다. 본문 카드의 접기 디자인은 유지합니다.

코멘트 입력창의 엔터와 빈 줄은 출력 HTML의 `<br>`로 유지합니다. 직접 입력한 `<br>`·`<br/>`·`<br />`도 줄바꿈으로 표시하며, 다른 HTML 태그는 일반 글자로 표시합니다. 정돈 기능은 본문 카드에만 적용하고 코멘트의 줄바꿈과 내용은 보존합니다.

코멘트 입력창의 `Shift+Enter`도 줄바꿈으로 반영합니다. 미리보기 직접 편집에서는 기존처럼 `Enter`로 저장하고, `Shift+Enter`로 `<br>` 한 개에 해당하는 줄바꿈을 넣습니다.

## 저장과 백업

현재 작업은 사용 중인 브라우저에 자동 저장됩니다. 작업을 따로 보관하려면 보관함에 저장합니다. 다른 기기나 브라우저로 자동 동기화되지는 않습니다.

보관함의 **내보내기**로 JSON 백업을 만들고 **파일 가져오기**로 복원할 수 있습니다. HTML 저장하기·불러오기는 개별 작업을 옮길 때 사용할 수 있습니다.

## 내려받아 실행하기

1. [Releases](https://github.com/mosaic-log/mosaic-log.github.io/releases)에서 압축 파일을 내려받습니다.
2. 압축을 모두 해제하고 같은 폴더의 `index.html`을 브라우저에서 엽니다.

설치·빌드 과정은 없습니다. HTML·CSS·JS 파일을 같은 폴더 구조로 유지합니다. 웹폰트와 이미지 URL은 인터넷 연결이 필요하며, 웹사이트와 로컬 파일의 저장 공간은 다릅니다.

## 직접 수정하기

수정한 파일을 그대로 실행할 수 있습니다. 파일 구조와 수정 방법은 [개조 안내](MODDING.md), 유지보수 원칙은 [AGENTS.md](AGENTS.md)를 참고합니다.

[Issues](https://github.com/mosaic-log/mosaic-log.github.io/issues)에 사용 버전, 브라우저, 재현 순서를 남겨 주세요. 문제가 생기는 짧은 예시 본문이나 화면이 있으면 확인에 도움이 됩니다.


### 2026-11-13 원문 병행 보완

- `“Hello (안녕)”`과 `“Hello(안녕)”`을 같은 원문·번역으로 분리합니다. 괄호 앞 입력 공백 수와 관계없이 이어쓰기 출력은 한 칸으로 통일하고 입력 원문은 보존합니다.
- `“Hello(부가설명) again”`처럼 괄호 뒤에 대사가 이어지면 분리하지 않습니다. 기존 따옴표 바깥 번역도 지원합니다.
- 나레이션 원문 병행을 기본 ON으로 변경합니다. 저장된 OFF와 옛 전체 OFF는 유지합니다.
- 버전 1.9.9·저장 형식·기존 디자인은 유지합니다.

### 2026-11-13 번역 간격·스크롤바 보완

- 자동 배치 중 같은 줄로 표시되는 번역과 이어쓰기 번역은 원문과 한 칸 띄웁니다. 대사·속마음·나레이션, 원문/번역 우선, 괄호 표시/숨김에 같은 기준을 적용합니다. 아래쓰기의 줄 배치는 유지합니다.
- 입력 공백은 보존하며, 인식 대상이 아닌 괄호와 병행 제외 문장은 간격을 변경하지 않습니다.
- 스크롤바 기본 농도 25%, 막대 호버 농도 35%로 설정합니다. 호버 전후 트랙 11px·투명 테두리 2.5px를 고정하여 보이는 막대 두께 6px를 유지합니다(WebKit 지원 브라우저). 표준 스크롤바는 thin을 유지합니다.

### 2026-11-13 외부 스크롤바 두께 조정

- 화면 바깥·설정 영역·미리보기 영역의 스크롤바만 보이는 두께 8px로 확대합니다. 카드 입력 내부는 기존 6px를 유지합니다.
- 호버 전후 두께를 고정하고 색 농도만 25%에서 35%로 변경합니다. 차지하는 트랙 폭은 유지하여 내용 배치에 영향을 주지 않습니다.
- 위 픽셀 수치는 WebKit 스크롤바 지원 브라우저 기준입니다. 표준 스크롤바만 지원하는 브라우저에서는 기존 thin 설정을 유지합니다.

### 2026-11-14 폭 조절 경계 강조

- 설정·미리보기 사이 폭 조절 경계에 마우스를 올리거나 드래그할 때 3px 두께의 테마 강조색 선을 표시합니다. 키보드 포커스에도 같은 강조를 적용합니다.
- 평상시 표시와 9px 조작 영역, 좌우 반전 배치, 드래그 폭 조절·더블클릭 기본 폭 복원은 유지합니다.

### 2026-11-14 경계선 세부 조정

폭 조절 강조선을 3px로 축소하고 위아래 모서리를 각지게 변경합니다. 색상과 9px 조작 영역은 유지합니다.

### 2026-11-14 외부 스크롤·메모·인용 조정

- 외부 스크롤바는 보이는 두께 8px를 유지하고 양옆 투명 여유를 1.5px에서 3px로 확대합니다(트랙 14px). 기본 농도 25%는 유지하고 호버 농도를 35%에서 45%로 높입니다. 카드 내부 스크롤은 변경하지 않습니다.
- 인용 위아래 안쪽 여백은 13px에서 11px로, 메모는 12px에서 10px로 줄입니다. 좌우 여백·상자 사이 간격·글자 설정은 유지합니다.
- 메모 외곽선은 1.5px에서 1px로 조정합니다.
- 스크롤 픽셀 수치는 WebKit 스타일 지원 브라우저 기준이며, 표준 전용 브라우저는 기존 thin을 유지합니다.

### 2026-11-14 외부 호버 색상만 추가 조정

외부 막대 호버 농도만 45%에서 55%로 높입니다. 기본 농도25%·보이는 두께8px·양옆 여유3px는 유지하며, 카드 내부와 메모·인용은 변경하지 않습니다.

### 2026-11-14 외부 호버 두께 증가 버그 수정

외부 막대 호버의 background 단축 선언을 background-color로 바꾸어 background-clip:padding-box를 유지합니다. 이전에는 호버 시 border-box로 초기화되어 투명 테두리까지 색칠되었습니다. 이제 기본·호버 모두 막대8px·양옆여유3px이며 색 농도만 25%→55%로 바뀝니다.

### 2026-11-14 참고 사진 색상 적용

외부 스크롤바 기본색 #e4e4e5, 호버색 #585a5b를 적용합니다. 첨부 사진의 막대 중앙 색상을 추출한 값입니다. 기본·호버 모두 보이는 두께8px·양옆여백3px·padding-box 유지. 카드 내부 색상은 유지합니다.

### 2026-11-14 웜그레이 색상 적용

외부 스크롤 기본색 #d8d5cf·호버색 #96928a를 적용합니다. 호버 전후 두께8px·양옆여백3px·padding-box는 유지합니다. 카드 내부 스크롤과 다른 기능은 변경하지 않습니다.

### 2026-11-14 내부 스크롤 웜그레이 통일

내부 스크롤도 기본 #d8d5cf·호버 #96928a로 통일합니다. 내부 막대6px와 외부8px를 유지하고 호버 시 색상만 바뀝니다. 호버 색은 background-color로 지정해 padding-box를 보존합니다.

### 2026-11-14 이미지 출력 폭 고정

- 본문·코멘트 [IMG] 이미지는 편집과 미리보기에서 기존 @비율(%)을 유지합니다.
- HTML 복사·저장·카드별/코멘트별 복사에서는 현재 미리보기의 이미지 폭을 px로 환산합니다. 코드 보기에도 같은 출력 형식을 사용합니다.
- 원본 이미지 해상도가 아니라 현재 미리보기의 카드 안쪽·코멘트 영역 폭을 기준으로 계산합니다. 예: 영역600px × 50%=300px.
- 세로는 기존 height:auto와 원본 종횡비를 유지합니다. max-width:100%도 보존하여 출력물을 더 좁은 화면에서 볼 때 넘치지 않게 합니다.
- 접힌 영역은 출력 사본에서만 잠깐 열어 측정하며, 실제 접힘 상태를 바꾸지 않습니다. HTML 저장 파일의 복원 정보는 원래 % 입력을 보존합니다.
- 이미지가 없는 문서는 측정을 생략합니다.

### 2026-11-14 원문 병행 정밀 검사 수정

- `“Hello(안녕)”` 형식을 개별 병행 제외했을 때 `“Hello”(안녕)`으로 따옴표 위치가 바뀌던 오류를 수정합니다. 제외 상태에서는 원래 괄호와 따옴표 위치·공백을 보존합니다.
- 공백뿐인 번역 괄호는 대사·속마음·나레이션에서 병행 번역으로 분리하지 않습니다.
- 표시 순서·괄호 옵션·자동/이어쓰기/아래쓰기·표현 7종·원문 매핑·직접 편집·중복 문장 개별 제외를 검사했습니다. 실제 화면에서 제외·다시 적용·실행 취소·다시 실행·직접 편집·범위 스위치를 확인했습니다.

### 2026-11-14 최초1.9.9 대비 회귀 검사 보완

- 설정 패널·화면 폭 변경 뒤 코드 보기에 예전 이미지px가 남던 오류를 수정합니다. 코드 패널을 열거나 열린 상태에서 폭이 바뀌면 새 폭을 반영하고, 전체화면 코드도 진입 시 다시 생성합니다.
- 코멘트 이미지 캡션에도 이미지와 같은 출력px를 적용합니다. 입력과 미리보기는 기존% 유지.
- 고대비 모드의 시스템 스크롤색이 사용자 지정색보다 우선하도록 수정합니다.
- 이미지 실측을 UI(ui-preview-view.js)로 옮겨 문서 조립과 분리합니다.

### 2026-11-14 이미지 px 변환 롤백

- 이미지 실측·px 변환 함수를 제거하고 본문·코멘트 이미지와 캡션의 기존% 출력을 복원합니다.
- 전체·카드별·코멘트별 HTML 복사와 HTML 저장에서 같은% 스타일을 유지합니다.
- 각 영역 폭을 기준으로 하며 이미지 기준 통일 작업은 적용하지 않습니다.
- 원문 병행·표제 마감·메모/인용·스크롤·고대비·코드 보기 갱신 등 나머지 검사 완료 수정은 유지합니다. 버전1.9.9·저장/복원 형식은 유지합니다.
