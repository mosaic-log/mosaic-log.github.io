# 조각로그 · Mosaic Log

대사와 나레이션을 꾸미고, 완성한 로그를 HTML로 내보내는 웹 도구입니다.

[바로 사용하기](https://mosaic-log.github.io/) · [업데이트 내역](https://github.com/mosaic-log/mosaic-log.github.io/releases) · [오류 제보·제안](https://github.com/mosaic-log/mosaic-log.github.io/issues)

## 주요 기능

- 카드 단위 본문 작성, 코멘트와 본문 메모 삽입
- 대사·나레이션·프로필·이미지·표제 디자인 설정
- 대사·나레이션 원문 병행, 표시 순서·괄호·부분 제외 설정
- 미리보기 직접 편집, 클릭·타이핑 위치 연동, 찾기·바꾸기
- 이름·키워드 치환과 특정 부분의 제외·다시 적용
- 현재 작업 자동 저장, 보관함과 디자인 프리셋 관리
- HTML 복사·내보내기·불러오기, 보관함 JSON 백업·복원

## 사용 방법

1. [조각로그](https://mosaic-log.github.io/)에 접속합니다.
2. 처음 열리는 본문 탭에서 글을 입력하고 카드·프로필·디자인을 설정합니다.
3. 미리보기에서 결과를 확인하고 수정합니다.
4. **HTML 복사하기** 또는 **HTML 내보내기**로 결과를 저장합니다.

본문 문법은 작업 화면의 안내에서 확인할 수 있습니다. 기본 표지 이미지는 없으며, 표지가 필요하면 표지 탭에서 직접 이미지 URL을 넣을 수 있습니다.

### 미리보기 편집

- 문장을 클릭해 직접 편집할 수 있습니다.
- 편집 중 `Enter`는 저장, `Shift+Enter`는 같은 문단 안 줄바꿈, `Esc`는 취소입니다.
- 꼬리말에 표시된 작성자 이름을 클릭해 수정할 수 있습니다. 이름이 없으면 표지 탭의 꼬리말 작성자 입력란에서 추가합니다. 두 곳의 수정 내용은 서로 반영됩니다.
- 꼬리말의 조각로그 링크는 [조각로그 웹사이트](https://mosaic-log.github.io/)로 연결됩니다. 미리보기에서는 링크를 눌러도 이동하지 않습니다.
- 원문 병행의 제외·다시 적용은 글자를 드래그한 뒤 선택 도구막대에서 실행합니다. 선택한 글자가 속한 원문·번역 묶음 전체에 적용됩니다.
- 병행 대사의 보조 문장은 원문·번역 표시 순서와 관계없이 바깥 큰따옴표를 생략합니다. 입력 원문과 문장 안의 인용은 유지됩니다.
- 이름·키워드 치환의 부분 제외는 해당 부분을 클릭하거나 드래그해 실행합니다.

### 작업 저장

현재 작업과 보관함은 사용 중인 브라우저에 저장됩니다. 다른 기기·브라우저로 자동 동기화되지 않으며, 웹사이트와 로컬 파일의 저장 공간도 다릅니다.

보관함의 **내보내기**로 JSON 백업을 만들 수 있습니다. **분할 내보내기**는 전체 항목을 10개씩 나누어 저장합니다. HTML 내보내기·불러오기는 개별 작업을 옮길 때 사용할 수 있습니다.

## 내려받아 실행하기

1. [Releases](https://github.com/mosaic-log/mosaic-log.github.io/releases)에서 사용할 버전의 압축 파일을 내려받습니다.
2. 압축을 모두 해제합니다.
3. 같은 폴더의 `index.html`을 브라우저에서 엽니다.

설치·빌드 과정은 없습니다. HTML·CSS·JS 파일을 같은 폴더 구조로 유지해야 합니다. 웹폰트와 URL로 불러오는 이미지 등은 인터넷 연결이 필요합니다.

## 직접 수정하기

개발용 코드와 배포용 코드가 같으며, 수정한 파일을 그대로 실행할 수 있습니다. JS는 공통 파일 5개와 UI 파일 6개, 총 11개입니다.

- 화면 디자인: `styles.css`, `index.html`
- 디자인 기본값과 데이터 정의: `state.js`
- 본문 해석과 출력 HTML: `parser.js`, `renderer.js`
- UI 기능: `ui.js`와 `ui-*.js`
- 저장·복원과 앱 실행 흐름: `storage.js`, `app.js`

파일별 책임과 수정 예시는 [직접 개조 안내](MODDING.md), 유지보수 원칙은 [AGENTS.md](AGENTS.md)를 참고합니다.
